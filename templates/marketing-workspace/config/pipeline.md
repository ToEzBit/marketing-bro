# ค่าตั้งของ pipeline

แก้ค่าใน frontmatter ด้านบนได้เลย ทุก skill อ่านไฟล์นี้ตอนเริ่มรอบ

- `target_page` ต้องเป็นเพจที่บัญชีที่ล็อกอินใน browser ของบอทเป็น admin
- `draft_expire_days` ใช้กับ draft ที่ `trend:` ไม่ใช่ `none` เท่านั้น — ของเกาะกระแสที่ไม่มีใครเลือกภายในกี่วันก็ตายไปเอง ส่วน evergreen (`trend: none`) รอในกองได้ตลอดไป
- `drafts_per_run` มีไว้กันรอบเดียวจับ browser ยาวเกินไป (1 draft = gen รูป 1 ครั้ง = จับ browser ทั้งระบบ) ตั้งสูงได้ถ้าอยากมีของให้เลือกเยอะ แต่ยิ่งสูงยิ่งไปเบียดคิวของ fb-publisher — ของที่ทำมาแล้วไม่มีใครเลือกไม่เสียหาย ถ้ามาจากเทรนด์มันจะหมดอายุเองตาม `draft_expire_days` ถ้าเป็น evergreen ก็รอในกองต่อไป
- `posts_per_day` เป็น **ค่าตั้งต้น ไม่ใช่กฎ** — คนที่อนุมัติปฏิทินใส่มากกว่านี้ได้ ตัวร่างแผนแค่เตือน (เพดานที่บังคับเงียบ ๆ ตอนโพสต์ถูกยกเลิกไปแล้ว ดู ADR 0011)
- **ไฟล์นี้ไม่มีค่าที่เกี่ยวกับเวลาโพสต์เลย** — เวลาโพสต์อยู่ในปฏิทิน (`calendar/`) ที่เดียว ส่วนเวลาที่บอทตื่นมาดูปฏิทินอยู่ที่ `at:` ของ Schedule ตัว fb-publisher ดูได้จาก `/schedule list` ใน Discord · Slot จะขึ้นในรอบตรวจแรกที่มาถึงหลังเวลาของมัน
- **อย่าตั้ง window ถี่เกินไป** — ระยะห่างระหว่าง window คือเวลาที่รอบนั้นรอคิว browser ได้ (ADR 0006) ตั้งห่างกัน 3-4 ชั่วโมงแปลว่ารอได้เป็นชั่วโมง ๆ ถ้าตั้ง 8-12 รอบต่อวันจะเหลือรอไม่กี่สิบนาที และการรอไม่ทันนับเป็นรอบล้มเหลว (ครบ 3 ครั้งติด schedule จะพักตัวเอง)
- เลข :30 ในตัวอย่างไม่ใช่ของขลัง — แค่ให้ไม่ออกตัวพร้อม trend-scout (08:00) กับ content-maker (10:00) พอดีเป๊ะ
- เพิ่มแพลตฟอร์มใหม่ในอนาคต: เพิ่มค่าใน `platforms` + สร้าง `brand/voice/<platform>.md` + ต้องมี skill โพสต์ของแพลตฟอร์มนั้นก่อน
