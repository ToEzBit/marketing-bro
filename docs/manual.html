01

บอทตัวนี้คืออะไร

มันไม่ใช่แชตบอทที่ตอบข้อความอย่างเดียว — มันคือ Claude ที่นั่งอยู่หน้าเครื่อง Mac เครื่องหนึ่งของทีม เปิดไฟล์ได้ เปิดเบราว์เซอร์จริงได้ และโพสต์ลงเพจ Facebook ของแบรนด์ได้จริง คุณคุยกับมันผ่าน Discord เท่านั้น

3 อย่างที่ควรรู้ก่อนใช้

  • บอทอยู่บนเครื่องจริง — ถ้าเครื่องนั้นปิด สลีป หรือเน็ตหลุด บอทก็เงียบไปด้วย ไม่มีอะไรทำงานบนคลาวด์
  • บอทใช้บัญชีจริงที่ล็อกอินค้างไว้ — เวลามันโพสต์ Facebook คือโพสต์ในนามเพจจริง ไม่ใช่เดโม และมันทำได้ทีละงาน เพราะมีเบราว์เซอร์อยู่ตัวเดียว
  • ทุกอย่างจดไว้เป็นไฟล์ — เทรนด์ที่เจอ คอนเทนต์ที่เขียน และปฏิทินโพสต์ อยู่ในโฟลเดอร์กลางชื่อ marketing-workspace บนเครื่องนั้น บอทลืมบทสนทนาได้ แต่ไฟล์ไม่หาย
สรุปสั้นสุด

งานที่บอททำเองทุกวันคือ หาเทรนด์ → เขียนดราฟต์ → โพสต์ตามปฏิทิน · งานที่ คน ต้องทำคืออย่างเดียว: เลือกว่าชิ้นไหนขึ้นเมื่อไร แล้วอนุมัติ ถ้าไม่มีใครอนุมัติ จะไม่มีอะไรถูกโพสต์เลย

02

สั่งงานยังไง

ในห้อง Discord ของทีม พิมพ์เครื่องหมาย / แล้วเมนูคำสั่งจะเด้งขึ้นมา เลือกคำสั่ง กรอกช่อง prompt (คือสิ่งที่อยากให้ทำ พิมพ์เป็นภาษาคนได้เลย) แล้วกด Enter

ตัวอย่าง — พิมพ์ในห้องหลักของทีม
/task prompt:"สรุปให้หน่อยว่าตอนนี้มีดราฟต์ค้างอยู่กี่ชิ้น อะไรบ้าง"

บอทจะตอบว่า 🧵 กำลังเปิดเธรดสำหรับ: … แล้วเปิดเธรดใหม่ให้ งานทั้งชิ้นเกิดขึ้นในเธรดนั้น

คำสั่งที่ใช้จริง

คำสั่งใช้ตอนไหน
/taskงานหลักทุกอย่าง — บอทเปิดเธรดให้ คุยต่อในเธรดได้เรื่อย ๆ
/askถามสั้น ๆ ตอบในห้องเดิม ไม่เปิดเธรด · ถามได้อย่างเดียว แก้ไฟล์หรือโพสต์ไม่ได้
/schedule listดูงานอัตโนมัติที่ตั้งไว้ทั้งหมด ว่ารอบต่อไปกี่โมง อันไหนหยุดอยู่
/stopสั่งหยุดงานในเธรดที่คุณอยู่ตอนนั้น
/statusดูว่าตอนนี้บอทกำลังทำอะไรอยู่ ใครถือเบราว์เซอร์อยู่ ใครต่อคิว
/helpสรุปคำสั่งย่อ ๆ ใน Discord (เห็นคนเดียว)

เธรดคือที่ทำงานของงานนั้น

  • คุยต่อได้ — พิมพ์ข้อความธรรมดาในเธรด ไม่ต้องมี / บอทจำเรื่องที่คุยกันมาทั้งเธรด
  • แทรกได้ระหว่างมันทำงาน — พิมพ์แทรกไปเลย บอทจะติด 👀 บนข้อความคุณ แปลว่ารับเรื่องแล้วและจะเอาไปทำต่อ
  • อยากให้หยุด — พิมพ์ /stop ในเธรดนั้น
ระวังจุดนี้

ถ้าคุณสั่ง /task ซ้ำในเธรดเดิม = สั่งให้เริ่มงานใหม่ทั้งชิ้น บอทจะลืมที่คุยกันมาก่อนหน้า · อยากสั่งเพิ่มเฉย ๆ ให้พิมพ์เป็นข้อความธรรมดาแทน

ข้อความสถานะในเธรด แปลว่าอะไร

ระหว่างทำงาน บอทจะมีข้อความหนึ่งบรรทัดที่แก้ตัวเองไปเรื่อย ๆ นั่นคือ "ตอนนี้กำลังทำอะไรอยู่"

เห็นแบบนี้แปลว่า
กำลังคิดกำลังประมวลผล ยังไม่ได้ลงมือทำอะไรกับเครื่อง
กำลังใช้ ชื่อเครื่องมือกำลังอ่านไฟล์ / เขียนไฟล์ / กดเว็บอยู่ ปกติดี
รอ browser ว่าง — ถือโดย … (คิวที่ 2)ไม่ได้ค้าง — เบราว์เซอร์มีตัวเดียว งานอื่นใช้อยู่ ของคุณต่อคิวรออยู่
รออนุมัติจากผู้ใช้มีปุ่มขึ้นในเธรดรอคุณกด (ดูหัวข้อ 6)
❌ งานล้มเหลว: …งานจบแบบไม่สำเร็จ อ่านเหตุผลที่ต่อท้าย แล้วสั่งใหม่หรือถามบอทต่อในเธรดได้เลย

03 · หัวใจของงาน

จากเทรนด์ถึงโพสต์

คอนเทนต์หนึ่งชิ้นเดินผ่าน 4 ขั้นเสมอ สามขั้นบอททำเองตามเวลา เหลือขั้นที่ 3 ที่เป็นของคน

ขั้น 1

ส่องเทรนด์

บอทไล่ดูโซเชียล เจอกระแสอะไรก็จดเก็บไว้เป็นไฟล์

บอททำเอง
ขั้น 2

เขียนดราฟต์

เอาเทรนด์มาเขียนเป็นโพสต์ พร้อมรูปประกอบ กองไว้รอคนเลือก

บอททำเอง
ขั้น 3

วางปฏิทิน + อนุมัติ

คนเลือกว่าชิ้นไหนขึ้นวันไหนกี่โมง แล้วเซ็นอนุมัติ

คนต้องทำ
ขั้น 4

โพสต์ลงเพจ

ถึงเวลาแล้วบอทหยิบไปโพสต์ตามที่อนุมัติไว้ คำต่อคำ

บอททำเอง

ทำไมต้องแยกขั้น 3 ออกมา: บอทไม่มีสิทธิ์ตัดสินใจว่าอะไรควรออกสู่สาธารณะ ปฏิทินคือคำสั่งของคน — ถ้าไม่มีชื่อคนอนุมัติในแถวนั้น บอทจะไม่โพสต์เด็ดขาด

ขั้นที่ 3 ทำยังไง

พิมพ์ในห้องหลัก (ไม่ใช่ในเธรดเก่า)
/task skill:content-calendar prompt:"วางแผนโพสต์อาทิตย์หน้า"

บอทจะเสนอแผนมาให้ พร้อม โชว์ข้อความเต็มและรูปของทุกชิ้น ในเธรดนั้น ให้คุณอ่านก่อนตัดสินใจ

จากนั้นคุยกับมันเป็นภาษาคนได้เลย เช่น เลื่อนวันพุธเป็น 19:00 · เอาชิ้นวันศุกร์ออก · สลับชิ้นเช้ากับชิ้นเย็น พอใจแล้วค่อยอนุมัติ

พิมพ์ในเธรดเดิม — ต้องมีชื่อคุณ
อนุมัติทั้งอาทิตย์ — สมชาย

ชื่อที่คุณพิมพ์จะถูกเซ็นลงในปฏิทินเป็นหลักฐานว่าใครอนุมัติ

3 กฎที่ทำให้ "โพสต์ไม่ขึ้น" — จำไว้ให้ขึ้นใจ

1. แถวไหนไม่มีชื่อผู้อนุมัติ = ไม่ถูกโพสต์ และจะไม่มีใครเตือนคุณด้วย มันเงียบไปเฉย ๆ · วางแผนแล้วต้องอนุมัติเสมอ

2. แก้เนื้อดราฟต์หลังอนุมัติแล้ว = การอนุมัติเป็นโมฆะทันที ต้องกลับไปอนุมัติใหม่ · กติกานี้มีไว้กันของที่คนยังไม่ได้อ่านหลุดออกเพจ

3. เวลาในปฏิทินแปลว่า "ไม่ก่อนเวลานี้" ไม่ใช่ "ตรงเวลานี้เป๊ะ" บอทตื่นมาดูปฏิทินเป็นรอบ ๆ ชิ้นที่ตั้งไว้ 13:00 จะขึ้นในรอบตรวจแรกหลังจากนั้น อาจเป็น 13:30

ของด่วน อยากขึ้นเดี๋ยวนี้

ไม่มีทางลัดข้ามปฏิทิน (ตั้งใจออกแบบไว้แบบนั้น) แต่ทำได้เร็วแบบนี้: สั่ง content-calendar ให้ใส่ช่องเวลาเป็นเวลาตอนนี้ → อนุมัติ → แล้วสั่งให้รอบโพสต์ทำงานเดี๋ยวนั้นเลยด้วย /schedule run (ดูหัวข้อ 5)

04

สั่งของนอกรอบ

ไม่ต้องรอรอบอัตโนมัติ อยากได้อะไรสั่งได้เลยด้วย /task แล้วเลือกช่อง skill — สกิลคือ "สูตรงาน" ที่สอนบอทไว้แล้วว่างานแบบนี้ต้องทำยังไง ถ้าไม่เลือก บอทจะเดาเองจากสิ่งที่คุณพิมพ์ (ส่วนใหญ่เดาถูก แต่เลือกเองชัวร์กว่า)

สกิลทำอะไรใคร
content-calendarวางแผน แก้ และอนุมัติปฏิทินโพสต์ประจำสัปดาห์คนสั่ง
evergreen-makerเขียนคอนเทนต์จากโจทย์ที่คุณบอก ไม่ต้องเกาะเทรนด์ (แนะนำสินค้า โปรโมชัน how-to) — ของแบบนี้ไม่มีวันหมดอายุ เก็บไว้ใช้เมื่อไรก็ได้คนสั่ง
review-draftดู/แก้/ตีกลับดราฟต์ทีละชิ้น สั่งทำรูปใหม่ หรือกู้ชิ้นที่โพสต์พลาดคนสั่ง
image-genสั่งสร้างรูปผ่าน ChatGPT แล้วส่งไฟล์รูปกลับมาให้ในเธรดคนสั่ง
trend-scoutส่องเทรนด์ในโซเชียลแล้วจดเก็บไว้อัตโนมัติ
content-makerเอาเทรนด์ที่จดไว้มาเขียนเป็นดราฟต์พร้อมรูปอัตโนมัติ
fb-publisherโพสต์ชิ้นที่ปฏิทินบอกว่าถึงเวลาแล้ว — ห้ามแก้ข้อความแม้แต่ตัวเดียวอัตโนมัติ
workspace-janitorเก็บไฟล์ที่จบงานแล้วเข้ากรุ และรายงานชิ้นที่ค้างผิดปกติอัตโนมัติ
อยากได้คอนเทนต์แนะนำสินค้า ไม่เกาะเทรนด์
/task skill:evergreen-maker prompt:"ทำโพสต์แนะนำ AI Card 3 ชิ้น คนละมุม"

ได้มาแล้วยังไม่ขึ้นเพจ — ต้องเอาไปใส่ปฏิทินและอนุมัติก่อนเสมอ

อยากแก้ดราฟต์ที่มีอยู่
/task skill:review-draft prompt:"ขอดูดราฟต์ที่ยังไม่ได้ลงปฏิทินทั้งหมด"

แล้วคุยต่อในเธรดได้เลย เช่น ชิ้นที่ 2 ตัดย่อหน้าสุดท้ายออก หรือ ชิ้นนี้ไม่เอา ตีกลับ

อยากได้รูปเฉย ๆ
/task skill:image-gen prompt:"รูปนามบัตร NFC สีชมพูวางบนโต๊ะไม้ แสงธรรมชาติ"

บอทจะแนบไฟล์รูปกลับมาในเธรด โหลดไปใช้ได้เลย

05

งานอัตโนมัติ

งานที่บอททำเองซ้ำ ๆ ตามเวลาเรียกว่า schedule แต่ละอันมีเธรดถาวรของตัวเอง ทุกรอบที่มันทำงานจะรายงานต่อกันในเธรดนั้น ย้อนดูได้ว่ารอบไหนเกิดอะไร

ดูว่ามีอะไรตั้งไว้บ้าง
/schedule list

แต่ละบรรทัดอ่านแบบนี้ — ไอคอนหน้าสุดบอกสถานะ ตามด้วยรหัส (id) ที่เอาไปใช้สั่งงานต่อ, รอบเวลา, รอบถัดไปกี่โมง, ลิงก์เธรด และเจ้าของ

ไอคอนแปลว่า
🟢กำลังทำงานอยู่ตอนนี้
⚪ปกติ รอถึงรอบถัดไป
⏸️หยุดอยู่ — ไม่ทำงานจนกว่าจะมีคนสั่งให้กลับมา

สั่งอะไรได้บ้าง

คำสั่งทำอะไรใครสั่งได้
/schedule pause id:…เบรกฉุกเฉิน — หยุดงานนั้นไว้ก่อน เช่นรู้ว่าคอนเทนต์มีปัญหาแล้วยังไม่อยากให้โพสต์อะไรออกไปอีกทุกคน
/schedule resume id:…ปลุกให้กลับมาทำงานตามรอบเหมือนเดิมเจ้าของ + คนดูแล
/schedule run id:…สั่งให้ทำเดี๋ยวนี้ 1 รอบ ไม่ต้องรอเวลาเจ้าของ + คนดูแล
/schedule create …ตั้งงานอัตโนมัติอันใหม่ — ต้องสั่งในห้องหลักเท่านั้น สั่งในเธรดไม่ได้ทุกคน

ตั้งงานอัตโนมัติเพิ่มเองได้ แต่บอกคนดูแลด้วยทุกครั้ง — ตั้งถี่เกินไปแต่ละรอบจะแย่งเบราว์เซอร์กันจนรอไม่ทันแล้วกลายเป็นรอบล้มเหลว · รอบโพสต์วันละ 3–6 รอบคือช่วงที่ปลอดภัย

บอทหยุดเองได้

ถ้า schedule อันไหน ล้มเหลว 3 รอบติดกัน บอทจะพักมันเองแล้วแท็กเจ้าของว่า ⏸️ … หยุดตัวเองแล้ว — ล้มเหลว 3 รอบติด · อาการที่คุณจะสังเกตเห็นคือ "อยู่ ๆ ก็ไม่มีโพสต์ขึ้นเลย" — เช็คด้วย /schedule list ว่ามี ⏸️ ไหม แก้ต้นเหตุก่อนแล้วค่อย resume

06

ปุ่มขออนุมัติ

บางครั้งบอทจะขึ้นกล่อง ⚠️ ขออนุมัติ พร้อมปุ่ม 3 ปุ่มในเธรด แปลว่ามันกำลังจะทำอะไรที่ย้อนกลับไม่ได้และอยากให้คนยืนยันก่อน

ตอนนี้เครื่องตั้งไว้ให้ผ่านเกือบทุกอย่างโดยไม่ถาม — สิ่งที่ยังถามเสมอคือ คำสั่งที่ลบไฟล์หรือล้างงานทิ้ง ฉะนั้นถ้าเห็นปุ่มนี้ ให้ถือว่าเป็นเรื่องใหญ่และอ่านให้ดี

  • อ่านบรรทัดบนสุด — บอทแปลคำสั่งเป็นภาษาคนไว้ให้แล้ว เช่น "ลบ build ทั้งโฟลเดอร์รวมทุกอย่างข้างใน — ไม่ได้เข้าถังขยะ กู้คืนไม่ได้" · คำอธิบายนี้บอทถอดจากตัวคำสั่งเอง ไม่ใช่คำที่ตัวมันเขียนมาเอง เชื่อได้
  • ถ้าไม่ใช่สิ่งที่คุณสั่ง กด "ปฏิเสธ" — ปฏิเสธไม่ทำให้อะไรพัง บอทจะหาทางอื่นหรืออธิบายว่าติดตรงไหน
  • ถ้าเห็นข้อความว่า "บอทไม่รู้จักคำสั่งนี้ จึงอธิบายให้ไม่ได้" = ไม่แน่ใจให้ปฏิเสธไว้ก่อน แล้วถามคนดูแล
  • ไม่มีใครกดภายใน 10 นาที = ถือว่าปฏิเสธอัตโนมัติ
  • กดได้เฉพาะ คนที่สั่งงานนั้น กับ คนดูแลบอท — คนอื่นกดจะขึ้นว่าไม่มีสิทธิ์

ปุ่ม "อนุมัติและจำไว้" = อนุญาตแบบเดียวกันนี้ไปจนจบงานชิ้นนั้น ไม่ต้องกดซ้ำ (จำแค่ในงานนั้น ไม่ข้ามไปงานอื่น) · ถ้าวันไหนคุณเริ่มเห็นปุ่มขออนุมัติบ่อยกว่าที่เขียนไว้ตรงนี้ แปลว่าคนดูแลปรับให้บอทระวังตัวมากขึ้นแล้ว ไม่ใช่บอทเสีย

07 · เปิดหน้านี้ตอนมีปัญหา

อาการ → วิธีแก้

หาแถวที่ตรงกับ ข้อความที่คุณเห็นจริง ๆ บนจอ

คุณเห็น / คุณเจอแปลว่าทำยังไง
โพสต์ที่วางไว้ไม่ขึ้นเพจ แต่ไม่มี error อะไรเลย เกือบทุกครั้งคือ 1 ใน 3 กฎในหัวข้อ 3: ไม่มีชื่อผู้อนุมัติ / แก้ดราฟต์หลังอนุมัติ / ยังไม่ถึงรอบตรวจถัดไป สั่ง /task skill:content-calendar prompt:"เช็คให้หน่อยว่าทำไมชิ้น … ยังไม่ขึ้น" — บอทเช็คให้ครบทั้ง 3 ข้อ
บอทนี้จำกัดเฉพาะทีมภายใน บัญชีของคุณไม่อยู่ในรายการที่อนุญาต Discord ของคุณยังไม่ถูกเพิ่มเข้าทีม ทักคนดูแลให้เพิ่มให้
ตั้ง schedule ได้ในห้องข้อความหลักของเซิร์ฟเวอร์เท่านั้น (ไม่ใช่ในเธรด) คุณสั่งอยู่ในเธรด กลับไปห้องหลักแล้วสั่งใหม่
เธรดนี้เป็นของ schedule — สั่งรอบใหม่ด้วย /schedule run เธรดนี้เป็นของงานอัตโนมัติ ห้ามเอามาเปิดงานใหม่ทับ อยากให้รันเดี๋ยวนี้ใช้ /schedule run id:… · อยากสั่งงานอื่นให้เปิด /task ในห้องหลัก
รอ browser ว่าง — ถือโดย … (คิวที่ 2) ปกติ ไม่ได้ค้าง — เบราว์เซอร์มีตัวเดียว งานคุณต่อคิวอยู่ พอถึงคิวจะไปต่อเอง รอ · อยากดูภาพรวมว่าใครถืออยู่ใช้ /status · ไม่อยากรอแล้วก็ /stop
♻️ งานถูกขัดจังหวะเพราะบอทรีสตาร์ต บอทเพิ่งถูกเปิดใหม่ระหว่างที่งานคุณทำอยู่ พิมพ์ต่อในเธรดเดิมได้เลย มันทำต่อจากเดิม
♻️ บริบทเดิมของเธรดนี้หมดอายุแล้ว ความจำภายในของงานนั้นบนเครื่องหายไปแล้ว — เจอกับเธรดเก่ามาก ๆ หรือหลังเครื่องถูกล้างประวัติ · ไม่ใช่เพราะเธรดเงียบไปพักหนึ่ง (เงียบเฉย ๆ พิมพ์ต่อได้ปกติ) พิมพ์อีกครั้งได้เลย บอทจะเริ่มให้ใหม่ — เล่าบริบทที่จำเป็นซ้ำอีกรอบ ข้อความเก่าในเธรดยังอ่านได้อยู่
⏸️ … หยุดตัวเองแล้ว — ล้มเหลว 3 รอบติด งานอัตโนมัติอันนั้นพักตัวเองแล้ว จะไม่ทำงานอีกจนกว่าจะปลุก เปิดเธรดของมันอ่านว่ารอบก่อน ๆ ล้มเพราะอะไร แก้ต้นเหตุ แล้ว /schedule resume id:…
❌ รอบนี้ล้มเหลว: … รอบนั้นทำไม่จบ (เน็ตหลุด เว็บเด้ง login ฯลฯ) รอบถัดไปยังทำงานตามปกติ ถ้าล้มซ้ำ ๆ ให้เรียกคนดูแล — บ่อยที่สุดคือเพจหลุด login
บอทเงียบทั้งวัน ไม่มีรอบไหนทำงานเลย เครื่องที่บอทรันอยู่ปิด สลีป หรือบอทไม่ได้เปิดอยู่ เรียกคนดูแลไปเปิดเครื่อง/เปิดบอท — ไม่มีใครสั่งจาก Discord ได้
ดราฟต์ขึ้นสถานะ missed เลยวันของช่องเวลาที่วางไว้แล้วยังไม่ได้ขึ้น ให้ช่องเวลาใหม่ด้วย content-calendar แล้วอนุมัติอีกครั้ง
ดราฟต์ขึ้นสถานะ post-failed บอทเริ่มโพสต์แล้วมีอะไรพังกลางทาง — ต้องมีคนไปดูหน้าเพจก่อนว่าตกลงโพสต์ติดไปหรือเปล่า เปิดเพจดูด้วยตาก่อน แล้วสั่ง /task skill:review-draft บอกมันว่าเห็นอะไร — บอทจะไม่โพสต์ซ้ำเอง
รูปที่ขอไม่มา หรือเว็บที่บอทเปิดค้างหน้า login บัญชีบนเบราว์เซอร์ของบอทหลุด หรือมีหน้าต่าง Chrome ของคนค้างอยู่ เรียกคนดูแล — เขาต้องล็อกอินใหม่แล้วปิดหน้าต่างนั้น ไม่งั้นรอบต่อไปของบอทเปิดเบราว์เซอร์ไม่ขึ้น

08

ศัพท์ที่ได้ยินบ่อย

คำแปลเป็นภาษาคน
Task (งาน)งานหนึ่งชิ้นที่คุณสั่ง = 1 เธรด · คุยต่อในเธรดได้จนกว่าจะพอใจ
Draft (ดราฟต์)คอนเทนต์หนึ่งชิ้น = ข้อความโพสต์ + รูป · ยังไม่ขึ้นเพจจนกว่าจะมีคนวางลงปฏิทินและอนุมัติ
Trend (เทรนด์)กระแสที่บอทเจอบนโซเชียลแล้วจดไว้เป็นวัตถุดิบ
ปฏิทิน (Content Calendar)แผนโพสต์ของสัปดาห์ — ชิ้นไหนขึ้นเมื่อไร ใครอนุมัติ · เป็นของคน บอทห้ามแก้เอง
Slot (ช่องเวลา)หนึ่งแถวในปฏิทิน = เวลาหนึ่งช่อง + ดราฟต์หนึ่งชิ้น · เวลาหมายถึง "ไม่ก่อนเวลานี้"
Schedule (งานอัตโนมัติ)กลไกตั้งเวลาของบอท ทำให้มันตื่นมาทำงานเอง — คนละอย่างกับปฏิทิน
Skill (สกิล)สูตรงานสำเร็จรูปที่สอนบอทไว้แล้ว เลือกได้ตอนสั่งงาน
Workspaceโฟลเดอร์กลางบนเครื่องที่เก็บทุกอย่างของทีม — เทรนด์ ดราฟต์ รูป ปฏิทิน
Operator (คนดูแล)เจ้าของเครื่องที่บอทรันอยู่ คนเดียวที่แก้การตั้งค่า ล็อกอินเว็บ และเปิด-ปิดบอทได้
